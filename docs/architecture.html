Factory Inventory Management System

A full-stack demo: a Vue 3 single-page app talks over HTTP/JSON to a FastAPI service that serves mock data held in memory. There is no database. Everything is loaded from JSON files when the server starts.

Data flow: a filter change on the Dashboard

Every filtered view follows the same path from user input to rendered numbers.

User changes a filter

FilterBar.vue writes to the shared refs in useFilters: selectedPeriod, selectedLocation, selectedCategory, selectedStatus. These refs are created once at module level, so every component sees the same state.

The view's watcher fires

The view's watch([...filters]) calls its load function, and getCurrentFilters() maps the UI names to API names (location becomes warehouse, period becomes month).

The API client builds the request

api.js leaves out any filter set to 'all' and fires parallel requests. For example, Dashboard sends /dashboard/summary, /orders, /inventory and /backlog through Promise.all.

FastAPI filters in memory

apply_filters() narrows by exact warehouse and case-insensitive category and status. filter_by_month() matches YYYY-MM as a substring of order_date, or expands Q1-2025…Q4-2025 into three months.

Aggregate and validate

Summary endpoints compute totals such as inventory value (qty × unit cost), low stock (qty ≤ reorder point) and pending orders (Processing or Backordered). List endpoints are checked against their Pydantic response_model.

Render

Responses go into refs (allOrders, inventoryItems). Computed properties derive the chart and table data, and useI18n translates labels and switches currency (JPY in Japanese mode).

Things worth knowing

Things I found while reading the code that aren't obvious from the docs.

Missing endpoints

api.js calls /tasks and /purchase-orders, but neither exists in main.py. Task calls from App.vue will return 404.

Data never persists

The JSON files are read once at import time. A restart resets all state, and there are no write endpoints today.

Filtering is uneven across views

Inventory has no time dimension, so it ignores Period. total_backlog_items on the summary ignores every filter. Spending only reacts to Period.

Hard-coded to 2025

QUARTER_MAP and the quarterly report only know about 2025 quarters. Orders from other years are left out of the quarterly report.

Inconsistent patterns

Reports.vue uses the Options API and hard-codes the API URL instead of going through api.js. Backlog.vue exists but has no route.

Mock auth only

useAuth returns a static, locale-aware user. There is no login or session. CORS allows every origin, which is fine for a local demo only.
